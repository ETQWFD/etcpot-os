EtcPot OS

基于 AOSP 16 的自定义安卓系统。全局重命名、全新圆角音量面板、C/C++ 自渲染桌面（仿 HarmonyOS NEXT）、极光动态壁纸、一键刷写安装。

下载镜像 在 GitHub 上查看

全局品牌重命名

系统属性、framework-res、设置应用全部替换为 EtcPot OS。

全新音量面板

半透明圆角设计，HarmonyOS 风格滑块与动画。

C/C++ 桌面

NDK + OpenGL ES 自渲染，移除 Launcher3，上滑抽屉。

极光动态壁纸

GLSL 流动渐变背景，随时间漂移。

自定义开机动画

支持把视频一键转成 AOSP bootanimation.zip。

一键安装

Linux / macOS / Windows 脚本，fastboot 全自动刷写。
